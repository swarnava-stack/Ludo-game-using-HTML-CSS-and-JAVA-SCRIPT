# 🎲 Ludo Game Using HTML, CSS & JavaScript

A simple and interactive **Ludo Game** developed using **HTML**, **CSS**, and **JavaScript**.  
This project recreates the classic board game experience in a web browser with colorful UI and game logic.

---

# 🚀 Features

- 🎮 Multiplayer Ludo gameplay
- 🎲 Dice rolling functionality
- 🟢 Player token movement
- 🏁 Winning detection system
- 🎨 Responsive and colorful UI
- ⚡ Built completely using Vanilla JavaScript

---

# 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
